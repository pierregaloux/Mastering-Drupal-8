ℹ️ Instructions

For Beginners: This dashboard displays real-time flight data from Microsoft Flight Simulator.

Currently Running: DEMO MODE - Displaying simulated data

To connect to real MSFS:

  1. Install MSFS SDK from Microsoft Flight Simulator Developer Documentation
  2. Add reference to SimConnect.dll in the project
  3. Update SimConnectService.cs with actual SimConnect API calls
  4. Start MSFS and this application will automatically connect

Access from Tablet: Open this page using your computer's IP address (e.g., http://192.168.1.100:5000) from your tablet browser when both devices are on the same network.
